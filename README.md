## 📂 Featured Projects

### 01 — 🤖 TechNova RAG AI Chatbot

**AI-Powered Company Knowledge Base Assistant**

A Retrieval-Augmented Generation (RAG) chatbot that allows users to ask questions about company policies and receive responses grounded in information retrieved from PDF documents.

**Technologies:** n8n · OpenAI GPT-5 mini · Supabase · Google Drive · PostgreSQL / pgvector

**Key Features:**

- PDF document ingestion from Google Drive
- Automated document text extraction and chunking
- OpenAI vector embedding generation
- Supabase vector database storage
- Semantic document retrieval
- AI Agent with conversational memory
- Document-grounded question answering
- Handling of questions unsupported by available documents

**Project Highlights:**

- Two connected n8n workflows
- Three successfully stored document chunks and embeddings in the demonstration
- Successful vector similarity search
- Tested chatbot responses and follow-up questions
- Workflow JSON exports and architecture screenshots included

**Status:** Completed Working Prototype
